# Portfolio Project

This is a personal **portfolio website** designed to showcase selected
projects across multiple disciplines, including **data architecture**,
**DevOps**, **backend development**, and **front-end engineering**.

Built with **React** and bundled using **Vite**, the site delivers a
fast, modern, and highly modular foundation that makes it easy to
maintain, extend, and present work professionally.

------------------------------------------------------------------------

## 🚀 Tech Stack

-   **React** --- UI framework\
-   **Vite** --- Lightning-fast bundler & dev server\
-   **TypeScript** --- Type-safe components and cleaner code\
-   **Tailwind CSS / ShadCN (optional)** --- For styling and UI
    consistency\
-   **React Router** --- Navigation between sections\
-   **Netlify / Vercel / GitHub Pages** (optional) --- Deployment
    options

------------------------------------------------------------------------

## 📁 Project Structure

``` bash
src/
  components/       # Reusable UI pieces (cards, sections, layout)
  pages/            # Routed pages (About, Projects, Contact)
  constants.ts      # Data sources (project metadata, links)
  hooks/            # Custom hooks
  assets/           # Static images & icons
  App.tsx           # App root
  main.tsx          # Entry point
```
